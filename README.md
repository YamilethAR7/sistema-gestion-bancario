# Sistema dGB
## Descripción
Este ejercicio corresponde al módulo 4.
El objetivo es desarrollar un sistema bancario utilizando JavaScript, programación orientada a objetos y módulos.
El ejercicio se irá construyendo por versiones, agregando diferentes funciones hasta completar el sistema completoo.

## Tecnologías utilizadas

- HTML5
- CSS3
- JavaScript
- Node.js y npm
- Git y GitHub

## Organización del proyecto

Para organizar el código se crearon diferentes carpetas:

- **models:** contendrá las clases del sistema bancario.
- **services:** se utilizará para los servicios.
- **ui:** contendrá la interfaz de usuario.
- **utils:** contiene las funciones auxiliares.
- **tests:** se utilizará para las pruebas.

## Funciones realizadas

En esta versión se crearon tres archivos:

- **validadores.js:** permite validar campos obligatorios y montos.
- **auxiliares.js:** genera identificadores para los registros.
- **formateador.js:** permite dar formato a monedas, fechas y números de cuenta.

También se utilizaron import y export para conectar las funciones entre diferentes archivos JavaScript.

## Cómo ejecutar el proyecto

1. Abrir la carpeta del Sistema de Gestión Bancaria en Visual Studio Code.
2. Abrir index.html con Live Server.
3. Abrir la console del navegador para comprobar los resultados.
